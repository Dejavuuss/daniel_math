- ✅ Слой данных `js/auth.js` на Firebase Auth + Firestore с прежним контрактом `apiGet` / `apiPost`.
- ✅ Правила доступа `firestore.rules`: ученик — только свои записи, родитель — записи ребёнка, писать может только репетитор.
- ✅ Создание аккаунтов учеников и родителей из панели репетитора (вкладка «Аккаунты»).
- ✅ Демо-режим на тестовых данных, пока Firebase не подключён.
- ✅ Скрипты миграции `migration/export-sheets.gs` → `migration/import.mjs` (пароли переносятся).

- ✅ Сквозная проверка на эмуляторах Auth + Firestore: импорт выгрузки, вход всеми ролями, создание аккаунтов, задания, сообщения, удаление — 22/22, без ошибок в консоли.
- ✅ Старый `Code.gs` перенесён в `legacy/`.

- Имя репетитора вместо логина в сообщениях у ученика (сейчас правила не дают ученику читать чужой профиль — понадобится публичная коллекция с именами).
