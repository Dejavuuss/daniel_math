# Кабинет репетитора — Google Apps Script + Google Sheets

Статический фронтенд для GitHub Pages, API на Google Apps Script, данные в Google Sheets. Без сборки и дополнительных библиотек. Интерфейс стал спокойнее: нейтральные цвета, тонкие границы, компактные цитаты на страницах.

## Листы Google Sheets

Создайте Google-таблицу. В `users` используйте заголовки `username | password | name | role | grade | child`. Допустимые роли: `admin`, `student`, `parent`. Для родителя `child` — логин привязанного ученика; для ученика заполните `grade`. Остальные листы:

- `materials`: `id | title | grade | url | description`
- `homework`: `id | student | title | assigned | due | status | link`
- `schedule`: `id | date | time | type | title | description | student`
- `grades`: `id | student | subject | grade | date | comment`

При первом API-запросе Code.gs создаёт отсутствующий лист `grades` и добавляет недостающие заголовки. Рекомендуется всё равно создать листы заранее, чтобы проще проверять таблицу. Не удаляйте и не переименовывайте заголовки.

## Деплой GAS

1. Google Sheets → Extensions → Apps Script.
2. Замените содержимое `Code.gs` кодом из проекта, сохраните.
3. Если Apps Script привязан к таблице, оставьте `SPREADSHEET_ID` пустым; для отдельного проекта укажите ID таблицы.
4. Deploy → Manage deployments → Edit (карандаш) → New version → Deploy. При первом запуске используйте New deployment → Web app.
5. Исполнение от имени владельца; доступ к веб-приложению — `Anyone`, если это соответствует вашей политике доступа.
6. URL `/exec` уже находится в `js/auth.js`. Если URL деплоя изменится, замените `APPS_SCRIPT_URL` там.

## GitHub Pages

Загрузите файлы проекта в корень ветки, которую публикует GitHub Pages (обычно `main` / root). Структура: `index.html`, `dashboard.html`, `parent.html`, `admin.html`, `css/style.css`, `js/*.js`, `Code.gs`. Затем GitHub → Settings → Pages и проверьте выбранные ветку и папку.

## Возможности

- Администратор создаёт материалы, домашние задания с ссылкой на видео/ресурс, события календаря, оценки и аккаунты родителей.
- Электронный дневник: оценки по математике, алгебре и геометрии, дата и комментарий.
- Родительский кабинет: расписание, статус домашних заданий, оценки и материалы только привязанного ученика.
- Ученик видит собственные задания и материалы своего класса и отмечает выполнение домашней работы.
- Сервер проверяет токен сессии и роль при каждом запросе. GET требует токен и возвращает данные, отфильтрованные по роли.
- POST использует `Content-Type: text/plain;charset=utf-8`, чтобы избежать CORS preflight.
- На каждой странице есть небольшая цитата известного учёного; цветовая тема — сдержанная, с переключателем светлой/тёмной темы.

## Безопасность

Этот проект — лёгкая персональная система, не полноценная школьная информационная система. Пароли в листе `users` хранятся как текст; для реального использования применяйте уникальные пароли и не храните лишние персональные данные. `Anyone` означает, что веб-приложение вызывается публично, но операции должны проходить серверную проверку токена. Не размещайте токен/пароли в общедоступных таблицах или исходниках. После обновления `Code.gs` обновите существующий deployment до New version; при изменении только HTML/CSS/JS достаточно GitHub Pages.
