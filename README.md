# Сайт репетитора по математике — Google Apps Script + Sheets

Статический фронтенд для GitHub Pages; серверная часть — Google Apps Script (GAS), база — Google Sheets. Сборка и библиотеки не нужны.

## 1. Создайте Google-таблицу

Создайте таблицу и четыре листа с точными названиями и заголовками в первой строке:

- `users`: `username | password | name | role | grade`
- `materials`: `id | title | grade | url | description`
- `homework`: `id | student | title | assigned | due | status`
- `schedule`: `id | date | time | type | title | description | student`

Имена столбцов должны совпадать, регистр имеет значение. В листе `schedule` столбец `student` необязателен для отображения всем ученикам, но его удобно добавить последним. Даты вводите как `YYYY-MM-DD`, время как `HH:MM`. Роль — `student` или `admin`.

## 2. Разверните Apps Script

1. В Google Sheets откройте **Extensions → Apps Script**.
2. Замените содержимое редактора кодом из `Code.gs`.
3. Если проект создан из таблицы, `SPREADSHEET_ID` можно оставить пустым. Если это отдельный проект, вставьте ID таблицы между кавычками.
4. Сохраните проект. Выберите **Deploy → New deployment → Web app**.
5. Укажите **Execute as: Me** и **Who has access: Anyone** (или подходящую вашей организации настройку доступа).
6. Нажмите Deploy, пройдите авторизацию и скопируйте URL веб-приложения, заканчивающийся на `/exec`.

При изменении кода создайте новую версию через **Deploy → Manage deployments → Edit → New version → Deploy**.

## 3. Подключите фронтенд

URL предоставленного веб-приложения уже прописан в `js/auth.js`. Если в будущем создадите новый деплой GAS, замените значение `APPS_SCRIPT_URL` в этом файле. Он подключается на всех трёх страницах, поэтому менять URL в HTML не нужно.

## 4. Опубликуйте на GitHub Pages

1. Загрузите файлы проекта в репозиторий.
2. В GitHub откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните и откройте опубликованный адрес.

Для локальной проверки запустите из папки проекта `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

## 6. Что умеет сайт

- Вход проверяется на GAS; в `localStorage` сохраняются только профиль пользователя и временный токен сессии, не пароль.
- Кабинет загружает состояние одним GET-запросом без кеширования.
- Ученики видят материалы своего класса и общие материалы, только свои домашние задания и доступные им события.
- Статус домашнего задания сохраняется на сервере; интерфейс обновляется оптимистично и откатывается при ошибке.
- Администратор добавляет материалы, домашние задания и события, а также удаляет записи.
- Календарь показывает 2026 год с выбором месяца и цветными типами событий.

## 7. Важные ограничения безопасности

- `Anyone` делает веб-приложение доступным по URL. Не помещайте в таблицу лишние персональные или чувствительные данные.
- Пример хранит пароли в таблице в открытом виде, чтобы не усложнять первоначальную настройку. Используйте уникальные сильные пароли; для реального сервиса предпочтительнее полноценная система идентификации и хранение хешей с солью.
- Сессии выдаются GAS после успешного входа и проверяются на каждом изменяющем POST. Токен живёт до 6 часов; после истечения срока войдите заново.
- `localStorage` — не полноценная защищённая сессия: пользователь своего браузера может изменить локальные данные. Сервер не доверяет сохранённой роли, а повторно читает роль из таблицы и проверяет токен.
- GET возвращает данные приложения, но исключает пароли пользователей. При необходимости ограничить публичное чтение состояния, добавьте авторизацию и к GET.
- `text/plain;charset=utf-8` для POST используется, чтобы браузер не делал CORS preflight-запрос. Это не является самостоятельной защитой доступа.

## Файлы

- `Code.gs` — GAS API.
- `index.html` — вход.
- `dashboard.html` — кабинет ученика.
- `admin.html` — панель репетитора.
- `js/auth.js` — URL API, сессия и HTTP-запросы.
- `js/dashboard.js` — данные кабинета и оптимистичное обновление статуса.
- `js/admin.js` — формы администратора.
- `js/calendar.js` — календарь 2026.
- `css/style.css` — оформление и тёмная тема.
