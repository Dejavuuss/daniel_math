# Уроки с Даниилом — кабинет репетитора по математике

Личные кабинеты ученика, родителя и репетитора: материалы, домашние задания, оценки, заметки с занятий, расписание, платежи, достижения и сообщения.

- **Фронтенд** — статические страницы без сборки (`*.html`, `css/`, `js/`), публикуются на GitHub Pages или Firebase Hosting.
- **Бэкенд** — Firebase: вход через Firebase Authentication, данные в Cloud Firestore, права доступа — в [firestore.rules](firestore.rules).
- **Дизайн** — швейцарский стиль: белый фон, чёрная типографика Inter Tight, модульная сетка, красный, синий и жёлтый как сигнальные цвета; тёмная тема — по кнопке. Слева — вертикальная панель разделов, которая сворачивается до значков (на телефоне — выезжающее меню). В каждом кабинете — шедевр с математической идеей и раздел «Галерея» со всеми картинами и портретами учёных.

## Посмотреть без настройки (демо-режим)

Пока в [js/firebase-config.js](js/firebase-config.js) не вписан настоящий ключ, сайт работает на тестовых данных, которые хранятся в вашем браузере. Страницы — ES-модули, поэтому открывать их нужно через локальный сервер, а не двойным щелчком:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000 и войдите как `teacher`, `ivan` или `parent_ivan` с любым паролем. Сбросить демо-данные: в консоли браузера `localStorage.removeItem("tutor_demo_db")`.

## Подключение Firebase

1. **Проект.** [console.firebase.google.com](https://console.firebase.google.com) → *Create a project*. Google Analytics не нужен. Тариф Spark (бесплатный) подходит.
2. **Вход.** *Build → Authentication → Get started → Sign-in method → Email/Password* → включите первый переключатель.
3. **База.** *Build → Firestore Database → Create database* → Standard edition, регион поближе (например, `eur3`), режим *production*.
4. **Ключи сайта.** *Project settings → General → Your apps → Web (`</>`)* → зарегистрируйте приложение и скопируйте объект `firebaseConfig` в [js/firebase-config.js](js/firebase-config.js). Эти ключи не секретные — данные защищают правила.
5. **Правила доступа.** Либо через консоль: *Firestore → Rules* → вставьте содержимое [firestore.rules](firestore.rules) → *Publish*. Либо через CLI:
   ```bash
   npx -y firebase-tools@latest login
   npx -y firebase-tools@latest use --add          # выберите проект
   npx -y firebase-tools@latest deploy --only firestore:rules
   ```
6. **Данные** — перенесите из Google Sheets (следующий раздел) или создайте репетитора вручную:
   *Authentication → Users → Add user*: e-mail `teacher@math-tutor.example`, пароль от 6 символов → скопируйте *User UID*.
   *Firestore → Start collection* `users` → документ с ID `teacher` и полями: `username` = `teacher`, `uid` = скопированный UID, `name` = ваше имя, `role` = `admin`, `grade` = `null`, `child` = `""` (пустая строка).
   Учеников и родителей дальше заводите в панели репетитора, вкладка «Аккаунты».

Логин превращается в служебный адрес `логин@math-tutor.example` — письма на него не отправляются. Домен задан в `USERNAME_DOMAIN` в [js/firebase-config.js](js/firebase-config.js) и [migration/import.mjs](migration/import.mjs); если меняете — меняйте в обоих местах до создания аккаунтов.

## Перенос данных из Google Sheets

1. В Apps Script-проекте таблицы создайте файл с кодом из [migration/export-sheets.gs](migration/export-sheets.gs) и запустите `exportForFirebase`. В журнале появится ссылка на `sheets-export-….json` — скачайте его в папку `migration/` под именем `sheets-export.json`.
2. *Project settings → Service accounts → Generate new private key* — сохраните как `migration/service-account.json`. **Это полный доступ к проекту: не коммитьте и не пересылайте файл** (он уже в `.gitignore`).
3. Запустите:
   ```bash
   cd migration
   npm install
   npm run dry-run      # покажет, что будет перенесено, ничего не записывая
   npm run import
   ```
   Пароли сохранятся прежними. Пароли короче 6 символов Firebase не принимает — скрипт заменит их и напечатает новые.
4. Удалите `sheets-export.json` (в нём пароли открытым текстом) и `service-account.json`.

Старый бэкенд лежит в [legacy/Code.gs](legacy/Code.gs) — он больше не нужен, после проверки нового сайта Apps Script-деплой можно отключить.

## Публикация

- **GitHub Pages** — как раньше: файлы в корне публикуемой ветки.
- **Firebase Hosting** (по желанию, тот же проект): `npx -y firebase-tools@latest deploy --only hosting` — сайт появится на `https://<project-id>.web.app`. Служебные папки (`migration/`, `tests/`, `legacy/`, `worker/`) не публикуются — см. `ignore` в [firebase.json](firebase.json).

## Прикреплённые файлы

К материалам, домашним заданиям и сообщениям можно прикреплять фото, скриншоты и документы: PDF, Word, Excel, презентации, текст. Ограничения: до 5 МБ на файл и до 5 файлов за раз.

- **Репетитор** прикрепляет файлы в формах «Материалы», «Задания» и «Сообщения»: кнопкой, перетаскиванием или вставкой скриншота через **Ctrl+V** в любое поле формы.
- **Ученик и родитель** у каждого задания нажимают **«Прикрепить решение»**. На телефоне это сразу предлагает сфотографировать тетрадь.
- Фото показываются миниатюрами и открываются на весь экран по щелчку, документы скачиваются под своим именем.
- Большие фото с телефона автоматически уменьшаются до 1920 пикселей: текст и чертежи остаются читаемыми, а файлы занимают в разы меньше места.

**Кто что видит.** Работают те же правила, что и для записей:
- файлы материалов видны всем;
- файлы задания — только этому ученику, его родителю и вам;
- файлы сообщения — только участникам переписки.

Свой файл может удалить тот, кто его загрузил; вы можете удалить любой. При удалении задания, материала или сообщения удаляются и их файлы.

**Где хранятся.** Файлы хранятся прямо в базе Firestore, кусками по 0,9 МБ: Firebase Storage для новых проектов требует платный тариф. Бесплатного объёма Firestore — 1 ГБ на весь сайт — хватит на тысячи фотографий.

## Формулы

В любом тексте на сайте — материалах, заданиях, заметках, сообщениях, тестах, задачах — формулы пишутся в знаках доллара и отображаются как в учебнике:

| Пишете | Получится |
|---|---|
| `$x^2 + y^2$` | x² + y² |
| `$\frac{1}{2}$` | дробь ½ |
| `$\sqrt{x}$` | корень из x |
| `$\pi r^2$` | πr² |
| `$$...$$` | формула отдельной строкой по центру |

Под полями в панели репетитора есть предпросмотр — сразу видно, как формула будет выглядеть.

## Тесты

Вкладка «Тесты» в панели: название, тема, для кого (все ученики, класс или конкретный ученик) и вопросы трёх типов:
- **выбор варианта** — от 2 до 6 вариантов, правильный отмечается кружком;
- **число** — принимаются `0,5`, `0.5` и `1/2`;
- **короткий ответ** — без учёта регистра и буквы «ё».

Если допустимых ответов несколько, перечислите их через точку с запятой: `3; -3`.

Ученик проходит тест во вкладке «Тесты» и отправляет ответы один раз. Сразу после этого он видит балл и разбор: где ошибся и какой ответ правильный. До отправки правильные ответы скрыты правилами базы данных, подсмотреть их нельзя. Балл не хранится — он каждый раз считается из ответов ученика, поэтому подделать результат тоже нельзя.

Вы видите, кто сдал и с каким результатом, ответы каждого ученика и кто ещё не сдал. Кнопка «Пересдать» удаляет результат, и ученик сможет пройти тест заново. Родитель видит результаты и разбор в своём кабинете.

## Банк задач

Вкладка «Банк задач» в панели: тема, класс, сложность (лёгкая, средняя, сложная), условие, ответ и, при желании, решение. Ученик видит задачи только своего класса (и задачи без класса) во вкладке «Тренировка». Там две части:

- **Тренировка на оценку** — 5 случайных задач (по всем темам класса или по одной), засчитывается первый ответ. Шкала: 90% и больше — «5», от 75% — «4», от 50% — «3», меньше — «2». Оценка сразу попадает в успеваемость ученика, её видят родитель и репетитор (вкладка «Оценки»).
- **Свободная тренировка** — темы раскрываются по нажатию, попыток сколько угодно, можно открыть решение. Прогресс «решено 5 из 12» запоминается в браузере.

Несколько ответов (например, оба корня) ученик вводит через точку с запятой: `3; -3`.

## Сообщения

Писать может каждый каждому: ученик — репетитору, родителям и другим ученикам, родитель — любому участнику. Адресата выбирают из списка с именами. Свои сообщения можно удалить; репетитор может удалить любое. Родитель видит и переписку своего ребёнка. Число новых сообщений горит на кнопке раздела.

## Панель репетитора

- «Обзор»: занятия на сегодня и завтра, просроченные задания, новые сообщения, баланс оплат по ученикам, кнопка «Скачать копию (JSON)» со всеми данными.
- У каждой записи (материал, задание, событие, оценка, заметка, платёж, достижение, задача) есть кнопка «Изменить» — открывается окно с теми же полями, что при добавлении. У задания и события там же меняется статус.
- Домашнее задание можно выдать сразу нескольким ученикам или целому классу.
- В каждом разделе — поиск по тексту.
- Имя, класс и родителя ученика можно изменить в разделе «Ученики и родители» или кнопкой «Изменить имя и данные» в разделе «Классы».

## Аккаунты

Вкладка «Аккаунты» в панели: нажмите на имя ученика или родителя, чтобы изменить имя, класс, привязку к ребёнку или имя в родительном падеже, либо удалить аккаунт. При удалении ученика удаляются и привязанные к нему родители; галочка «и все записи» удаляет также задания, оценки, заметки, платежи, достижения, сообщения и результаты тестов. Логин удалённого аккаунта выдать заново нельзя — выберите другой.

Пароль каждый меняет сам: кнопка с ключом в шапке кабинета. Чужой пароль сайт сменить не может (на бесплатном тарифе Firebase это делает только сервер) — если ученик забыл пароль, сбросьте его в Firebase Console → Authentication.

## Кабинет родителя

Приветствие: «Здравствуйте, (имя)!» — имя берётся до запятой, так что «Наталья, мама Захара» превращается в «Наталья». Ниже вдвое мельче: «На сайте представлена успеваемость (имя ребёнка в родительном падеже)». Имя склоняется автоматически; если вышло неправильно, впишите нужную форму в карточке ученика («Имя в родительном падеже»).

Первая вкладка — «Пройдено»: сданные тесты с баллом, оценкой и разбором, выполненные задания и тренировки на оценку. Во вкладке «Расписание» — календарь с занятиями и сроками заданий, вверху страницы — ближайшие занятия.

## Галерея

В каждом зале — настоящая репродукция картины в золочёной раме, а ниже на каждой странице экспозиция: этюд «Математика картины», портреты учёных (Эйлер, Гаусс, Ковалевская, Эйнштейн, Ньютон, Лобачевский…) и зал искусства XX века (Кандинский, Малевич, Мондриан, Клее, Попова…). Все изображения — общественное достояние или CC0 с Wikimedia Commons, источники перечислены внизу страницы.

## Классы

Вкладка «Классы» в панели — первая. Ученики сгруппированы по классам, класс меняется выпадающим списком рядом с именем и сохраняется сразу. От класса зависит, что видит ученик: материалы, тесты и задачи для тренировки — только своего класса и общие.

## Домашнее задание с тестом

В форме «Выдать домашнее задание» есть поле «Тест (необязательно)»: в нём тесты для класса выбранного ученика и его личные. У ученика в задании появляется кнопка «Пройти тест». Как только тест сдан, задание само отмечается выполненным, а оценка за тест (по той же шкале) попадает в успеваемость.

## Списки сворачиваются

Все длинные списки разбиты на группы, которые раскрываются и сворачиваются по нажатию: материалы по классам, задания по ученикам (у ученика — «Просрочено», «В работе», «Выполнено»), оценки, заметки, платежи и достижения по ученикам, сообщения по собеседникам, тесты и банк задач по классам, события на предстоящие и прошедшие. Формы добавления в панели тоже свёрнуты, пока их не откроешь. Открытые группы остаются открытыми после сохранения записи.

## Учебная база

На сайт загружена готовая база для 1–11 классов:
- **274 задачи** в банке по 49 темам — от состава числа и таблицы умножения (1 класс) до логарифмов и производных (11 класс). У каждой есть ответ и пошаговое решение с формулами.
- **22 теста**, по два на класс: задачи плюс вопросы на понимание. Каждый ученик видит тесты своего класса.
- **Шпаргалки** с формулами (сокращённое умножение, квадратные уравнения, прогрессии, тригонометрия, логарифмы, производные…) и ссылки на бесплатные банки заданий: ФИПИ, «Решу ОГЭ», «Решу ЕГЭ».

Задачи не скопированы с других сайтов, а сгенерированы программой [content/build.mjs](content/build.mjs). Ответ каждой задачи вычисляется кодом, а проверка [content/verify.mjs](content/verify.mjs) дополнительно решает основные типы задач заново по тексту условия.

Вопросы тестов — отдельные задачи, которых нет в банке: они генерируются из секретного случайного числа, а файл `content/content.json` с ответами не хранится в репозитории и не публикуется. Так ответы тестов нельзя найти ни в «Тренировке», ни на GitHub.

Загруженные записи помечены `seed-` и редактируются в панели как обычные. Обновить базу или удалить её целиком (ваши собственные записи не затрагиваются):

```bash
CONTENT_LOGIN=danya CONTENT_PASSWORD=ваш_пароль node content/upload.mjs            # загрузить или обновить
CONTENT_LOGIN=danya CONTENT_PASSWORD=ваш_пароль node content/upload.mjs --remove   # удалить загруженное
```

## ИИ-ассистент

Кнопка чата «ИИ-ассистент» есть в правом нижнем углу всех страниц. Ассистент отвечает на любые вопросы посетителей — по любым предметам, языкам и темам, помогает с задачами, а о занятиях, ценах и записи рассказывает только по сведениям из `worker/tutor-info.md`. Ответы даёт языковая модель через [OpenRouter](https://openrouter.ai), а между сайтом и OpenRouter стоит бесплатный Cloudflare Worker [worker/src/index.js](worker/src/index.js). Схема такая: страница отправляет вопрос воркеру, воркер добавляет инструкцию и сведения о занятиях и обращается к OpenRouter. Ключ OpenRouter хранится только в секретах Cloudflare. К кабинетам и данным учеников у ассистента доступа нет. Карта не нужна: бесплатный план Cloudflare даёт 100 000 запросов в сутки.

**Модель.** Сейчас используются бесплатные модели OpenRouter — цепочка `MODELS` в начале [worker/src/index.js](worker/src/index.js). Если первая модель перегружена, OpenRouter сам пробует следующую. У бесплатных моделей два ограничения:
- **50 запросов в сутки и 20 в минуту на весь аккаунт OpenRouter.** Лимит общий с другими проектами на этом аккаунте, например с Telegram-ботом. Если купить кредиты на $10, лимит вырастет до 1000 запросов в сутки.
- **Ответы проще, чем у платных моделей.** Бесплатная модель хуже держит правило «сначала подсказка» и иногда сразу решает задачу.

Чтобы перейти на платную модель, пополните баланс на openrouter.ai/credits и замените `MODELS` на `["anthropic/claude-haiku-5.5"]`. Это примерно 0,05 ₽ за ответ. После замены задеплойте воркер заново.

**Подключение (один раз):**

1. **Аккаунт Cloudflare.** Зарегистрируйтесь на https://dash.cloudflare.com/sign-up — бесплатно, без карты.
2. **Сведения о занятиях.** Заполните [worker/tutor-info.md](worker/tutor-info.md): цены, формат, расписание и обязательно реальные контакты. Ассистент отвечает только по этому файлу. Всё, что записано в квадратных скобках, он считает неизвестным и предлагает уточнить у вас.
3. **Вход, хранилище, ключ и деплой** — выполняйте в папке `worker`:
   ```bash
   cd worker
   npm install
   npx wrangler login                              # откроется браузер — нажмите Allow
   npx wrangler kv namespace create LIMITS         # выведет id — впишите его в wrangler.toml вместо REPLACE_WITH_KV_NAMESPACE_ID
   npx wrangler secret put OPENROUTER_API_KEY      # вставьте ключ sk-or-…
   npx wrangler deploy                             # выведет адрес https://math-assistant.<поддомен>.workers.dev
   ```
4. Вставьте адрес из последней команды в `ASSISTANT_URL` в [js/firebase-config.js](js/firebase-config.js) и опубликуйте сайт. Пока `ASSISTANT_URL` пустой, кнопка ассистента скрыта.

**Защита.** Ассистент открыт всем, поэтому воркер:
- принимает запросы только с вашего сайта (`ALLOWED_ORIGINS`);
- пропускает не больше 10 сообщений в час с одного адреса и 30 в сутки со всего сайта (`PER_DAY`), чтобы сайт не съел всю бесплатную квоту OpenRouter и вашему боту остались запросы. Счётчики хранятся в Workers KV;
- ограничивает вопрос 1000 символами, а историю — 12 последними репликами;
- убирает из ответа разметку Markdown и LaTeX, которую модели иногда вставляют: окно чата показывает обычный текст.

**Если сменили `tutor-info.md`** или настройки в `worker/src/index.js`, выполните в папке `worker` команду `npx wrangler deploy`.

**Проверка у себя:** впишите ключ в `worker/.dev.vars` (`OPENROUTER_API_KEY=sk-or-…`; файл исключён из git) и выполните `npx wrangler dev`. Воркер запустится на http://127.0.0.1:8787.

## Аккаунты и пароли

- Репетитор создаёт учеников и родителей во вкладке «Аккаунты» — пароль задаётся при создании.
- Сменить пароль, отключить или удалить аккаунт — *Firebase Console → Authentication → Users*. Удалите и документ `users/<логин>` в Firestore: без него вход в кабинет невозможен.
- Пароли хранит Firebase Authentication в зашифрованном виде; в базе их больше нет.

## Тесты правил доступа

Правила проверяются на эмуляторе Firestore (нужна Java 21+):

```bash
cd tests
npm install
npm test
```

Тесты повторяют запросы, которые делает [js/auth.js](js/auth.js), и пробуют обойти права: чужие данные, подмену роли, подделку отправителя, некорректные поля.

## Безопасность

Доступ проверяется на стороне Firebase правилами [firestore.rules](firestore.rules): ученик видит только свои записи, родитель — записи своего ребёнка, менять данные может только репетитор (ученик и родитель — лишь отметку о выполнении задания и прочтении сообщений). Админа нельзя создать из приложения — только в консоли или скриптом миграции. Правила — проверенный тестами прототип; перед тем как раздавать доступ большому числу людей, стоит ещё раз их просмотреть.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `dashboard.html`, `parent.html`, `admin.html` | Вход и кабинеты ученика, родителя, репетитора |
| `js/auth.js` | Слой данных: вход, `apiGet` / `apiPost`, Firebase или демо |
| `js/firebase-config.js` | Ключи проекта Firebase |
| `js/demo.js` | Тестовые данные для демо-режима |
| `js/fx.js`, `js/art.js` | Движение (свет, пыль, появление) и анимированные гравюры |
| `js/ui.js`, `js/calendar.js` | Общие элементы интерфейса и календарь |
| `css/style.css` | Все стили, тёмная и светлая темы |
| `js/assistant.js` | Чат-виджет «ИИ-ассистент» |
| `worker/` | Cloudflare Worker ассистента (OpenRouter) и сведения о занятиях для него |
| `firestore.rules`, `firebase.json` | Правила доступа и настройки Firebase |
| `migration/` | Перенос данных из Google Sheets |
| `tests/` | Тесты правил на эмуляторе |
| `legacy/Code.gs` | Прежний бэкенд на Apps Script |
