# 📐 Личный кабинет репетитора по математике

Статический сайт для GitHub Pages: ученики входят по логину и паролю и видят материалы, домашние задания и календарь на 2026 год. У репетитора есть панель для добавления данных.

Чистые HTML + CSS + JavaScript, без сборки.

> **Скриншоты:** сделайте их после деплоя и положите в папку `docs/` (`docs/login.png`, `docs/dashboard.png`, `docs/calendar.png`), затем раскомментируйте строки ниже.

## ⚠️ Безопасность — прочитайте обязательно

**Это не настоящая защита, а разграничение доступа «для удобства».**

- GitHub Pages — статический хостинг без серверной части. Файлы `data/*.json` публичны: любой, кто знает адрес сайта, может открыть `https://<username>.github.io/math-tutor-site/data/users.json` или DevTools и прочитать все данные.
- Пароли в `users.json` по умолчанию лежат **в открытом виде**. Это учебный проект.
- Хеширование SHA-256 (поле `passwordHash`) скрывает пароль от случайного взгляда, но не защищает от подбора простых паролей.
- Не храните в репозитории персональные данные и платёжную информацию, не используйте здесь пароли, которые вы применяете где-то ещё.
- Для реальной защиты нужен бэкенд (Firebase, Supabase, Node.js на Vercel/Render и т.п.).

Репозиторий публичный, поэтому всё содержимое (в том числе PDF в `files/`) доступно всем.

## Запуск локально

Браузер не даёт `fetch` читать JSON с `file://`, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Деплой на GitHub Pages

1. Создайте **публичный** репозиторий, например `math-tutor-site`.
2. Загрузите в него все файлы проекта (в корень репозитория).
3. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, нажмите Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<username>.github.io/math-tutor-site/`.

Все ссылки в проекте относительные, поэтому работает и в подпапке репозитория.

## Как добавить ученика

**Вариант 1 — вручную.** Добавьте объект в `data/users.json`:

```json
{ "login": "maria", "password": "pass123", "name": "Мария Орлова", "role": "student", "grade": 10 }
```

**Вариант 2 — через админку** (вкладка «Ученики»): по умолчанию пароль сохраняется как SHA-256-хеш. После добавления нажмите «Скачать users.json» и замените файл в репозитории (или используйте отправку через GitHub API).

## Как поменять пароль

- Открытый пароль: измените поле `password` в `users.json`.
- Хеш: получите SHA-256 нового пароля и вставьте в `passwordHash` (удалите поле `password`). Получить хеш можно в терминале:
  ```bash
  printf '%s' "новыйпароль" | sha256sum
  ```
  или в консоли браузера:
  ```js
  crypto.subtle.digest("SHA-256", new TextEncoder().encode("новыйпароль"))
    .then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2, "0")).join("")))
  ```

## Как добавить материал

Добавьте запись в `data/materials.json`, а файл положите в `files/`:

```json
{ "id": 6, "title": "Логарифмы", "grade": 10, "url": "files/logarithms.pdf", "description": "Конспект" }
```

- `grade` — класс; ученик видит материалы своего класса. Без `grade` материал виден всем.
- `url` — путь к файлу в репозитории или внешняя ссылка (например, Google Drive).

## Как добавить задание

В `data/homework.json`:

```json
{ "id": 6, "student": "ivan", "title": "№ 300–305", "assigned": "2026-10-12", "due": "2026-10-19", "status": "pending" }
```

- `student` — логин ученика.
- `status`: `pending` или `done`. Ученик может сам отметить задание галочкой, но эта отметка хранится только в его браузере (localStorage) и вам не видна. Если вы проверили работу — поставьте `done` в JSON.
- Дедлайн автоматически появляется в календаре ученика.

## Как добавить событие в календарь

В `data/schedule.json`:

```json
{ "date": "2026-10-30", "time": "16:00", "type": "lesson", "title": "Занятие: логарифмы", "student": "ivan" }
```

- `type`: `lesson` 🔵 занятие, `deadline` 🟠 дедлайн, `test` 🔴 контрольная, `olympiad` 🟢 олимпиада.
- `student` необязателен: без него событие видят все ученики.

## Панель репетитора (`admin.html`)

Войдите под ролью `admin`. Формы добавляют записи в **черновик в вашем браузере**; удалять записи можно кнопкой ✕. Чтобы изменения увидели ученики:

1. нажмите «Скачать JSON» и замените файл в `data/` через коммит в GitHub; **или**
2. укажите репозиторий и токен в блоке «Отправка в GitHub» — панель сделает коммиты через GitHub API.

Для варианта 2 создайте fine-grained personal access token с правом **Contents: Read and write** только на этот репозиторий. Токен хранится в localStorage вашего браузера — используйте только на личном устройстве и не оставляйте на чужих компьютерах. Страница `admin.html` и сама видна в репозитории, но без токена изменить данные нельзя.

Черновик живёт в localStorage и имеет приоритет над файлами репозитория на этом устройстве. Если вы правили JSON вручную и не видите изменений в админке — очистите данные сайта в браузере (или выполните в консоли `["materials","homework","schedule","users"].forEach(n => localStorage.removeItem("tutor_draft_"+n))`).

## Дополнительно

- Тёмная тема переключается кнопкой 🌓, выбор запоминается.
- «Запомнить меня» хранит сессию в localStorage; без галочки — до закрытия вкладки.
- Год календаря задан константой `CAL_YEAR` в `js/calendar.js`.
